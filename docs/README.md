# Lazurite Project Documentation

- `docs/dev/` contains maintainer-facing explanations for implemented systems.
- `docs/specs/` is reserved for active or proposed designs that are not yet part
  of the developer guide.
- `docs/tasks/` tracks unfinished milestone work. Completed milestones should
  move to `CHANGELOG.md` and, when useful, `docs/dev/`.
- `docs/designs/` contains UI wireframes and design references.
- `docs/TODO.md` is the parking lot for smaller ideas and follow-ups.
